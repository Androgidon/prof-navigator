# CareerPath Profession Matrix — filled draft

Это заполненная матрица профессий для MVP assessment engine. Она составлена как экспертный rules-based draft для старта разработки и пилотирования. Логику рекомендуется калибровать после первых пользовательских данных и ручной валидации.

## Что внутри
- 100 профессий
- 10 кластеров
- target profile по 12 шкалам
- веса шкал
- critical dimensions
- important subjects
- hobby signals
- preferred environments
- why_fit template
- first_steps template

## Ограничение
Это не психометрически валидированный инструмент, а качественная экспертная матрица для MVP и дальнейшей калибровки.

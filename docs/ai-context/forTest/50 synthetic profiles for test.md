Сетка из 50 synthetic profiles для проверки профтеста

Как читать

Для каждого профиля есть:
	•	Название
	•	Короткое описание
	•	Ожидаемые сильные dimensions
	•	Ожидаемые top-кластеры
	•	Какие кластеры не должны лезть вверх

Группа 1. Analytical / Technical — 10 профилей

1. Системный аналитик-школьник
	•	Любит разбираться, как всё устроено, видеть логику, находить ошибки
	•	Сильные: analytical, technical, structured, detail
	•	Ожидается: IT, Data, QA, System Analysis
	•	Не должно лезть: helping-heavy, education-heavy, art/media

2. Логик-математик
	•	Сильный в задачах, формулах, логике, закономерностях
	•	Сильные: analytical, quantitative, detail
	•	Ожидается: Data, Finance, Analytics, QA
	•	Не должно: design/media, pure helping roles

3. Технический разборщик
	•	Любит чинить, настраивать, тестировать, искать причину поломки
	•	Сильные: technical, practical, analytical
	•	Ожидается: Engineering, IT, Automation
	•	Не должно: teaching/helping, content/PR

4. Внимательный тестировщик
	•	Любит проверять, искать несоответствия, доводить до точности
	•	Сильные: detail, structured, technical
	•	Ожидается: QA, Audit, Compliance, Operations QA
	•	Не должно: abstract science, generic marketing

5. Backend-тип
	•	Любит системы, логику, не любит много общения, ценит точность
	•	Сильные: technical, analytical, structured
	•	Ожидается: Backend, IT, Data Engineering
	•	Не должно: HR, counseling, media/content

6. Data-minded ученик
	•	Интересуется данными, таблицами, закономерностями
	•	Сильные: analytical, quantitative, technical
	•	Ожидается: Data Analyst, BI, Finance Analytics
	•	Не должно: design/media, pure social roles

7. Инженер-конструктор
	•	Любит собирать, понимать, как работают механизмы и процессы
	•	Сильные: technical, practical, detail
	•	Ожидается: Engineering, Automation, Robotics
	•	Не должно: marketing, psychology, literature-heavy roles

8. Процессный технарь
	•	Комфортно в чётких алгоритмах и последовательностях
	•	Сильные: structured, technical, detail
	•	Ожидается: Operations Engineering, QA, Technical Support high-skill
	•	Не должно: broad helping/education

9. Исследователь-логик прикладного типа
	•	Любит исследовать, но в прикладных системах, не в абстракции
	•	Сильные: analytical, technical, exploratory
	•	Ожидается: IT Research, Product/Systems Analysis, Data
	•	Не должно: historian, political science, generic science fallback

10. Техно-практик
	•	Не любит теорию без результата, любит “сделал — увидел”
	•	Сильные: practical, technical, structured
	•	Ожидается: Engineering, Operations Engineering, Automation
	•	Не должно: media/content, counseling

Группа 7. Edge cases / Stress cases — 5 профилей

46. Flat profile
	•	Почти везде средние ответы
	•	Сильные: нет ярко выраженных
	•	Ожидается: mixed / low-confidence / broad recommendations
	•	Не должно: очень уверенный и экстремальный top

47. Conflicting profile
	•	Высокий helping + высокий technical + низкий social + высокий detail
	•	Ожидается: сложный гибридный результат
	•	Не должно: один нелепый доминирующий кластер без объяснения

48. Overconfident noisy pattern
	•	Ответы почти везде экстремальные, но слабо согласованные
	•	Ожидается: lowered confidence
	•	Не должно: high confidence without caveats

49. Under-expressed uncertain
	•	Много “не уверен” и мягких значений
	•	Ожидается: medium/low confidence, broad safe results
	•	Не должно: high confidence and sharp cluster dominance

50. Helping vs marketing borderline
	•	Сильные verbal, social, умеренный helping, немного creative
	•	Ожидается: education/helping OR communication/marketing boundary
	•	Это хороший тест на то, где проходит граница между:
	•	helping/education
	•	marketing/content/business communication

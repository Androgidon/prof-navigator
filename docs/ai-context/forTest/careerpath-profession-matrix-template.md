# CareerPath Profession Matrix Template

Этот файл — шаблон для заполнения profession matrix для assessment engine.

## Как использовать
- Один ряд = одна профессия
- `target_*` = целевой профиль профессии по 12 шкалам (0–100)
- `weight_*` = важность шкалы для профессии (0.1–1.5)
- `critical_dimensions` = ключевые шкалы через `|`
- `important_subjects` = важные предметы через `|`
- `hobby_signals` = усиливающие хобби/сигналы через `|`
- `preferred_environments` = подходящая рабочая среда через `|`
- `why_fit_template` = шаблон объяснения “почему подходит”
- `first_steps_template` = первые шаги через `|`

## Градация target profile
- 85–95 — очень важно
- 70–84 — сильно желательно
- 55–69 — полезно
- 40–54 — нейтрально
- 20–39 — не драйвер
- 0–19 — почти не требуется

## Градация weights
- 1.5 — ключевая шкала
- 1.3–1.4 — очень важная
- 1.0–1.2 — важная
- 0.7–0.9 — поддерживающая
- 0.4–0.6 — второстепенная
- 0.1–0.3 — почти не влияет
